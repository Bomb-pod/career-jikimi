# 판정 백엔드 전환 — `.env` 한 줄로 셋 중 선택

```
JUDGMENT_BACKEND=openai     # OpenAI API
JUDGMENT_BACKEND=ollama     # 로컬 LLM (Qwen 등)
JUDGMENT_BACKEND=encoder    # 파인튜닝 인코더
```

`service.judge()`의 9단계, `judgment_logs`, 강행 전송, `report`/`evaluate`가
셋 다에서 **그대로** 동작한다. 셋 모두 같은 `ModelCall`을 돌려주기 때문이다.

`openai`와 `ollama`는 **같은 코드 경로**를 쓴다 — Ollama가 OpenAI 호환
엔드포인트를 내주므로 `base_url`과 모델명만 다르다. `client.call_model()`의
타임아웃·재시도·예산 계산(BR-6.7)을 두 벌로 만들지 않기 위해서다.

## 1. 새 파일 둘

| 파일 | 비고 |
|---|---|
| `backend/app/judgment/backend.py` | 백엔드 라우터 (새로 추가) |
| `backend/app/judgment/local_encoder.py` | 갱신본으로 교체 |

## 2. `core/config.py` — 판정 설정 블록에 추가

`AI_TIMEOUT_SECONDS` 아래에 넣는다.

```python
    # --- 판정 백엔드 선택 --------------------------------------------------
    # openai | ollama | encoder. 오타는 backend.active()가 기동 시 잡는다.
    JUDGMENT_BACKEND: str = "openai"

    # ollama — OpenAI 호환 엔드포인트. 컨테이너에서 호스트를 부르므로
    # localhost가 아니라 host.docker.internal이다.
    OLLAMA_BASE_URL: str = "http://host.docker.internal:11434/v1"
    OLLAMA_MODEL: str = "qwen3.5:4b"

    # encoder — 비우면 backend/models/context_checker 를 쓴다.
    ENCODER_MODEL_DIR: str = ""
    # 비우면 threshold.json → 그것도 없으면 AI_VERDICT_THRESHOLD.
    # **인코더는 LLM과 점수 스케일이 다르다.** 0.7을 그대로 쓰면 판정이 엉뚱해진다.
    ENCODER_THRESHOLD: float | None = Field(default=None, ge=0.0, le=1.0)
```

그리고 클래스 안 아무 곳에 프로퍼티 둘을 넣는다.

```python
    @property
    def active_model(self) -> str:
        """현재 백엔드가 쓸 모델명. client.call_model()이 이걸 본다."""
        if self.JUDGMENT_BACKEND.strip().lower() == "ollama":
            return self.OLLAMA_MODEL
        return self.OPENAI_MODEL

    @property
    def active_base_url(self) -> str | None:
        """None이면 SDK 기본값(OpenAI)."""
        if self.JUDGMENT_BACKEND.strip().lower() == "ollama":
            return self.OLLAMA_BASE_URL
        return None
```

## 3. `judgment/client.py` — 두 줄

```python
# get_client() 안
        _client = AsyncOpenAI(
            api_key=settings.OPENAI_API_KEY.get_secret_value(),
            base_url=settings.active_base_url,      # ← 추가
            max_retries=0,
        )

# call_model() 안, chat.completions.create(...)
                model=settings.active_model,         # ← OPENAI_MODEL 에서 변경
```

## 4. `judgment/service.py` — 두 줄

```python
# from app.judgment.client import call_model
from app.judgment.backend import call_model, verdict_threshold

# judge() 안
    threshold = verdict_threshold()      # ← float(settings.AI_VERDICT_THRESHOLD) 에서 변경
```

## 5. `main.py` startup (선택이지만 권장)

```python
from app.judgment import backend as judgment_backend

@app.on_event("startup")
async def _warm_judgment() -> None:
    await judgment_backend.warmup()
```

인코더는 299MB를 읽느라 첫 호출이 수 초 걸린다. 그대로 두면
`AI_TIMEOUT_SECONDS=4.0`을 넘겨 **첫 메시지가 `failed`가 된다.**
워밍업 실패는 기동을 막지 않는다.

## `.env` 예시

### OpenAI

```
JUDGMENT_BACKEND=openai
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-5.6-luna
AI_VERDICT_THRESHOLD=0.7
```

### Ollama

```
JUDGMENT_BACKEND=ollama
OLLAMA_BASE_URL=http://host.docker.internal:11434/v1
OLLAMA_MODEL=qwen3.5:4b
AI_VERDICT_THRESHOLD=0.7
OPENAI_API_KEY=ollama          # 무시되지만 필수 키다
```

### 인코더

```
JUDGMENT_BACKEND=encoder
ENCODER_THRESHOLD=0.35         # 비우면 threshold.json
OPENAI_API_KEY=unused          # 무시되지만 필수 키다
```

> `OPENAI_API_KEY`는 `config.py`가 기본값 없는 필수 키로 두었다.
> 백엔드와 무관하게 아무 문자열이나 있어야 앱이 뜬다.

## 컨테이너

`encoder`를 쓸 때만 필요하다. `requirements.txt`에:

```
transformers>=4.48
torch
```

`deploy/Dockerfile`의 python-build 스테이지에 CPU 전용 torch를 먼저 받는다
(안 하면 CUDA 빌드를 받아 이미지가 3GB 넘게 커진다).

```dockerfile
RUN pip wheel --no-cache-dir --wheel-dir /wheels \
      --index-url https://download.pytorch.org/whl/cpu torch
RUN pip wheel --no-cache-dir --wheel-dir /wheels -r requirements.txt
```

runtime 스테이지에 모델을 굽는다.

```dockerfile
COPY backend/models ./models
```

`openai`/`ollama`만 쓸 거면 **셋 다 필요 없다.** `backend.py`가 torch를
지연 import하므로 없어도 앱이 뜬다.

## 확인

```bash
docker compose exec app python -m app.judgment.try \
  --context "내일 배포 리허설 몇 시로 할까요?" "오전 10시면 될 것 같습니다" \
            "저는 10시 좋습니다" "롤백 절차도 봐주세요" \
  --candidate "오늘 저녁에 치킨 어때?"
```

기동 로그에 `판정 백엔드: encoder (모델 ..., 임계값 0.35)` 가 찍힌다.
`.env`의 `JUDGMENT_BACKEND`만 바꿔 다시 띄우면 다른 백엔드로 같은 명령이 돈다.

## 주의

- `client.get_client()`가 클라이언트를 **프로세스 공용으로 캐시**한다.
  백엔드를 바꿨으면 컨테이너를 재시작해야 한다 (`.env`만 고치고 재시작하면 된다 —
  `env_file`은 런타임에 읽는다).
- 백엔드마다 **임계값이 다르다.** LLM 0.7, 인코더는 threshold.json 값.
  `verdict_threshold()`가 알아서 고르고, 고른 값이 `judgment_logs.threshold`에
  저장되므로 나중에 재현할 수 있다.
