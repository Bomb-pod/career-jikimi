## 0. 먼저 — 무엇이 올라가는지 확인

**`backend/models/`(약 300MB)가 커밋되면 GitHub이 푸시를 거절한다** (파일당 100MB 제한).
`.gitignore`에 방금 추가했으니 아래로 확인한다.

```bat
cd C:\IDE\workplace\jihwan\mini_project

git status --short
git check-ignore -v backend\models\context_checker\model.safetensors
git check-ignore -v benchmark_out\encoder.csv
git check-ignore -v .env
```

`check-ignore`가 `.gitignore:NN:패턴` 을 출력하면 무시되는 것이다.
아무것도 안 나오면 **거기서 멈추고** `.gitignore`를 다시 볼 것.

이미 추적 중이었다면 인덱스에서 빼야 한다(파일은 남는다).

```bat
git rm -r --cached backend\models benchmark_out 2>nul
```

## 3. 커밋

```bat
git commit -F- <<"MSG"
feat(judgment): 판정 백엔드 전환(openai/ollama/encoder) + 인코더 파인튜닝

.env의 JUDGMENT_BACKEND 한 줄로 세 백엔드를 고른다. 셋 다 같은 ModelCall을
돌려주므로 judge()의 9단계, judgment_logs, 강행 전송, report/evaluate가 그대로
동작한다. openai와 ollama는 base_url만 다른 같은 코드 경로를 쓴다 — client의
타임아웃/재시도/예산 계산(BR-6.7)을 두 벌로 만들지 않기 위해서다.

판정 경로
- judgment/backend.py: 백엔드 라우터. torch를 지연 import해 LLM 백엔드에서는
  컨테이너에 torch가 없어도 앱이 뜬다. import 실패도 ModelCall(ok=False)로
  잡아 예외가 judge() 밖으로 새지 않는다 (BR-6.7).
- judgment/local_encoder.py: 인코더 어댑터. 조립된 프롬프트를 prompt.py의 절
  제목 상수로 되풀어 (문맥, 후보)를 얻고, torch 추론을 to_thread로 감싸
  이벤트 루프를 막지 않는다.
- 임계값 출처는 AI_VERDICT_THRESHOLD 하나로 유지한다. threshold.json은 기동 시
  경고에만 쓰고 덮어쓰지 않는다 — judgment_logs.threshold가 설정값과 같다는
  불변식(BR-6.5)을 지켜야 판정을 재현할 수 있다.
- main.py lifespan에서 warmup(). 인코더 첫 호출이 모델 로딩(300MB)을 포함해
  AI_TIMEOUT_SECONDS를 넘기면 첫 메시지가 failed가 된다.

모델
- 학습: v3 1000행. 화자 호칭을 A/B/C로 익명화해 운영 프롬프트(FR-6.2)와 형식을
  맞췄고, 부수적으로 검증 성능이 0.855 -> 0.890으로 올랐다. 호칭이 암기
  손잡이였다.
- 평가: test_dataset_100에서 AUC 1.000 / precision 1.000 / recall 1.000,
  절제 실험 AUC 1.000 -> 0.638로 문맥 사용 확인. p50 512ms(CPU), 4초 초과 0건.
- hard 셋은 AUC 0.728 / recall 0.020. 부적절 50건 중 46건이 지시 위반(N4/N3/N2)
  으로 프롬프트가 명시적으로 배제한 범주다. 오탐은 0 — 모르는 종류를 만나면
  조용히 넘어간다.

도구 (scripts/eval/)
- benchmark_three.py: 세 백엔드를 같은 평가셋에 올린다. 학습셋 누출 검사,
  양쪽 동일 익명화, AUC 병기, 절제 실험, 기저율 보정 precision, report.md 저장.
- check_local_llm.py / analyze_encoder_result.py / diagnose_ollama.py / eval_testset.py
- app/seed_demo.py: 데모 데이터. AI_CONTEXT_N=10 때문에 방마다 12턴 이상.

컨테이너
- requirements-encoder.txt 분리. torch는 CPU 전용 인덱스에서 받는다 — 기본
  PyPI 빌드는 CUDA를 포함해 이미지가 2GB 넘게 커지는데 GPU를 붙이지 않는다.
- COPY backend/models ./models. 가중치는 .gitignore로 커밋에서 뺀다.
- db 포트를 127.0.0.1:3307에 바인딩. 0.0.0.0이면 같은 공유기의 다른 기기에서도
  보인다.

테스트 355 passed / skip 0. conftest가 JUDGMENT_BACKEND=openai로 고정한다 —
judge()의 단위 테스트는 백엔드가 아니라 임계값 판정과 실패 처리를 검증하며,
.env가 encoder면 그 테스트들이 인코더 경로로 흘러 성립하지 않는다.
MSG
```

> `<<"MSG"` 힘독은 **Git Bash / PowerShell 7**에서 된다.
> cmd.exe면 `git commit` 만 치면 편집기가 열린다. 거기에 붙여 넣어도 된다.
