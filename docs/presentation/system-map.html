채팅방을 착각해 잘못 보낸 메시지를, 전송되기 전에 문맥으로 걸러낸다

컨테이너 2개 · uvicorn 워커 1개 고정 · 판정 백엔드 3종 교체 · 2026-08-03

프론트엔드 백엔드 판정 · 모델 데이터 외부 서비스 구조적 제약
워커를 늘리면 깨진다 WS 연결 레지스트리가 프로세스 메모리에 있어 --workers 2 이상이면 다른 워커에 붙은 사용자에게 메시지가 가지 않는다 (CON-1). 확장하려면 Redis pub/sub으로 먼저 바꿔야 한다.
저장 먼저, 브로드캐스트 나중 순서가 반대면 DB 쓰기 실패 시 화면엔 보이는데 새로고침하면 사라진다. 정렬은 created_at이 아니라 (room_id, seq)이고, 채번은 FOR UPDATE로 방 단위 직렬화한다.
검증은 참여자 개인별 room_members.ai_check_enabled. 방장이 켠다고 전원 적용되지 않는다 — 내 실수를 막는 기능이지 남이 내 전송 지연을 결정할 일이 아니다.
