## Q1 — FR-10(참여자 추가·나가기)을 이번에 만드는가

`scope-document.md`의 위험 등록부와 `requirements.md` ASM-8이 절단 순서를 **미리 정해두었다**:

> 1순위 **방 참여자 추가·나가기(FR-10)** → 2순위 degraded 회복 프로브(FR-8.5) → 3순위 오발송 신고(FR-11)

| 항목 | 값 |
|---|---|
| 오늘 | 2026-07-30 |
| 중간 점검 | 2026-07-31 (**내일**) |
| 최종 발표 | 2026-08-04 |
| 남은 단위 | U4(L, 지금 이것) + **U5(XL)** |
| 최상위 위험 | "07-31까지 Must 전량 완료" — 가능성 High / 영향 High |

U5는 다섯 단위 중 가장 크고, 전송·seq 채번·판정 통합·degraded 상태 기계가 **한 요청 경로 안에 얽혀 있어** 나눌 수 없다. FR-10은 **Should**이며 빼도 데모 시나리오가 성립한다 — 방을 만들고 대화하고 판정을 받는 흐름에 참여자 추가·나가기가 필요하지 않다.

계획은 이것을 **Step 7 하나에 격리**해두었다. 나중에 붙일 때 다른 단계를 건드리지 않는다.

- A. **지금 자른다 (추천)** — Step 7을 건너뛰고 U5로 간다. 미리 정해둔 절단 순서를 그대로 따르는 것이며, 이 결정이 U5에 반나절을 돌려준다. U5가 일찍 끝나면 그때 Step 7만 실행하면 된다
- B. **만든다** — 엔드포인트 2개 + 테스트 5~6개 + UI. FR-10.1·FR-10.2가 Must는 아니지만 데모에서 방에 사람을 더 부르는 장면을 보여줄 수 있다
- X. Other (please specify)

[Answer]: A. 지금 자른다 (추천) — 2026-07-30, **Mode:** guided

> Step 7을 실행하지 않는다. FR-10.1·FR-10.2는 미구현으로 남으며, 절단 순서상 다음 후보는 FR-8.5(degraded 회복 프로브)다. Step 7의 경계가 격리되어 있으므로 U5가 일찍 끝나면 그 단계만 실행해 되돌릴 수 있다.
